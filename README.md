# Gazette Metadata Workbench

Browse the metadata of every item in archive.org's `gazetteofindia` collection (860,525 rows, no PDFs) next to the SCC legislation tree, to work out which filters are worth using.

Separate from the Indian Legislation Explorer; it only reads that site's public JSON.

Rebuild: `scripts/build_site.py` in the egazette_context workspace.
